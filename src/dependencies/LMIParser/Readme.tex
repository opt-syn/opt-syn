Version 1 (July 15, 2025)

This is an LMI parser which permits to generate LMIs both in the format of LMIlab and Yalmip.
Unlike the path to call the LMIlab solver via Yalmip, the parser generates LMI descriptions
via the genuine implementation in LMIlab for optimal performance of the LMIlab solver.

For installation, just make sure that the folder lmiparser is accessible by Matlab.
To access LMIlab, the robust control toolbox needs to be accessible.

It implements the following four classes:

@lmibl:  Objects are LMI variables (matrix variable blocks) X,Y,Z,... to define affine maps.
@lmim:   Objects are LMI maps, affine maps in the format A+B*diag(X,Y,Z,...)*C.
@lmis:   Objects are LMI systems that define an LMI problem.
@lmival: Objects are LMI values (an array of doubles) e.g. as a result of optimization.

The folder functions comprises auxiliary commands outside the scope of these classes.
Moreover, the folder tests contains examples to showcase the use of the commands.
