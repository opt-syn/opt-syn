Objects sdpss are state-space systems which can be used for optimization with Yalmip
Any sdpss object is a structure which consists of four fields with natural interpretations:

sdpss.A
sdpss.B
sdpss.C
sdpss.D

-----------------------------------------------
Commands

tsso:   Shows how to use the tools

sdpss:  Convert matrix, Yalmip variable or ss to an sdpss object.
        One argument: For matrix or Yalmip variable, this results in a non-dynamic sdpss system.
        Four arguments: A,B,C,D lead to an sdpss system as for ss objects
